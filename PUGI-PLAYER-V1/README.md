# PUGI PLAYER V1

A GitHub Pages-ready PWA music player.

## Features
- Modern responsive PC/mobile UI
- Local music library
- Offline storage using IndexedDB
- Play/pause/next/previous
- Queue, shuffle and repeat
- Favorites
- Search
- Bass Boost and Treble controls using Web Audio API
- Presets: Normal, Deep Bass, Rock, Hip-Hop
- Visualizer
- PWA manifest + service worker

## Run
Open `index.html` through a local web server for full PWA/service-worker support.

For GitHub Pages:
1. Create a GitHub repository, e.g. `pugi-player`.
2. Upload all files/folders.
3. Settings -> Pages -> Deploy from branch -> `main` -> `/ (root)`.
4. Open the generated Pages URL.
5. On Android/Chrome or Edge, use Install/Add to Home Screen.

## Music
V1 stores music you add from your own device. Do not upload copyrighted music to GitHub without permission.
For an online catalog, connect a properly licensed music API/CDN in the next version.
